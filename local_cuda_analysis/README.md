# Owner-local complete-study reporting

This separate read-only adapter preserves the frozen remote reporting CLI. It
accepts only the original fixed four-arm registration and its authenticated
owner-local canonical binding, complete plan/acceptance, eight original CPU gold
rows, zero-credit CUDA qualification and32,760 new CUDA originals. All32,768 rows
must have complete source-specific owner actor-audit records before any result
is reported. Each CUDA row's source-closure and selected-batch registration
hashes bind its exact sealed snapshot/header/summary; accepted rows must match
the raw batch games hash and all80 turn action/final-state-chain links. It never
calls controllers, policies, referees or CUDA, and does
not require the recorded execution runtime to be active during analysis.

The original128-map/four-arm/four-field/16-seat-token crossing, integer twice-
pairwise cube and all six60,000-replicate map-bootstrap contrasts are unchanged:
seed202611091740 and tail indices249/59749. All means, fields, contrasts and
qualified uncertainty are reported. An observed leading mean alone is
inconclusive; even descriptive separation never promotes a policy automatically.

python -m local_cuda_analysis.report --registration .cache/confirmation/architectures_v2_001/registration.json --registry OWNER_PRIVATE_REGISTRY_PATH --output FRESH_REPORT.json

The registry and key remain private; the report contains no key material. Owner
HMAC authenticates trusted admission declarations, not host honesty, independent
hardware or physical CUDA execution. Exact CPU Python policies plus CUDA
physics are a mixed backend. Timings are descriptive, not a normalized speed
ranking. The report grants zero new primary/BMCTS/promotion credit.

Tests use explicitly synthetic32k metadata, a patched synthetic owner secret
and mocked source/oracle/gold/batch contexts. Targeted small synthetic batch
files separately test snapshot, summary, row-hash and80-turn bindings. Those rows were never physically played
and are not real study or qualification evidence. No real study output is read
during implementation/testing.
