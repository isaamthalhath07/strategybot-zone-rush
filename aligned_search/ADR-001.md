# ADR-001: Match the offline evaluator to the bot's continuation

**Status:** Accepted for a preregistered offline comparison; production choice remains open.
**Date:** 2026-11-09
**Deciders:** The current strategy implementation and independent review team, within the user's authorized research task.

## Context

The released standalone e8 policy is the current control. Its public-history MCTS teacher samples a correlated physical-state/rival-style posterior, then chooses future focal actions through a tree and an economic rollout. The causal evaluator instead forces one suggested root action and returns control to e8. Those continuation targets differ.

The completed, preregistered sixteen-position experiment found two improvements, three losses and eleven unchanged pairwise results. Mean change was -0.03125 on the official 0..3 scale, with descriptive interval [-0.21875, 0.15625]. This establishes no decision improvement. One loss occurred with six turns remaining and an exact terminal search, so simply extending the leaf horizon is not a sufficient explanation. See [the result](../intent_trials/evidence/causal_001/RESULTS.md) and [the independent strategy review](../intent_trials/evidence/causal_001/STRATEGY_REVIEW.md).

The constraints are exact public inputs, official simultaneous movement/Shield rules, persistent correlated posterior explanations, no silently pruned histories, independent referee agreement, unchanged frozen sources, and no production promotion from a selected TRAIN diagnostic. Existing runtime measurements exceed the regular 200 ms budget. A new offline evaluator must not be described as a qualified game actor or a completed per-game BMCTS audit.

## Decision

Implement a separate root-action evaluator. Reconstruct e8's own memory using only the complete public prefix and accepted own actions. Compute its original root proposal, retain the proposal's planner updates, synchronize the accepted action to the tested root alternative, and then let e8 choose every simulated future focal action. Each sibling branch has fresh function globals and independent copies of data-only policy memory. The policy never receives a sampled physical state, private counters, a rival type, a particle index or future transcript.

For six legal root actions, use sixteen paired posterior worlds, evaluating all six actions in each world: 96 trajectories with six mandatory two-referee transitions each. A world retains the complete joint physical/type sample and persistent rival types. Rival random keys are shared across root alternatives without taking the chosen focal action as an input; future public boards may cause different responses. This coupling reduces irrelevant between-action variation without conditioning rival simultaneous decisions on the tested move. The previous adaptive MCTS uses 96 sampled worlds; identical case seeds do not make these two algorithms' trajectories identical.

Choose the largest empirical root mean. Exact ties prefer the reconstructed e8 proposal, then fixed action order. This is a declared package choice, not a confidence bound or a guarantee against harmful deviations. Before a terminal state use the existing leaf proxy; at terminal use the exact official pairwise utility and never invent a turn-81 actor observation.

Compare the new package against the frozen teacher on sixteen new, disjoint admitted TRAIN maps, four per rival field, at turn 75 with all six actions legal. Select boundaries using the same fixed public score/income feature, never actual headroom or future outcomes. Freeze sources, exclusions, selection, seeds, capacities, metric and shared bootstrap recipe before recommendations or responding-controller alternatives run. Both recommendations use the same complete actual root-alternative set. A source, capacity, baseline-equivalence, actor, referee or completeness failure preserves evidence and fails the whole experiment.

## Options considered

| Option | Advantages | Costs and limitations |
| --- | --- | --- |
| Keep the frozen MCTS teacher | Existing reviewed implementation; preserves a route toward repeated future search control; correct joint inference and simultaneous physics | No demonstrated causal gain; future tree/economic behavior differs from the tested e8 continuation; offline latency exceeds the actor budget |
| Replace only the fallback rollout with e8 | Smaller algorithmic change; tests whether a better rollout helps future tree control | Tree-selected future actions still differ from the one-step hybrid target; maintaining accepted-action memory along tree paths is still necessary; not a complete target match |
| Root-only e8 continuation, selected here | Directly represents the declared one-step hybrid; paired complete root comparisons; reuses the frozen filter, rival model and referees | Removes future tree control, changes sample allocation and tie handling; only sixteen distinct worlds per action under this budget; extra policy calls and memory reconstruction cost; rival-model error remains |
| Add latent rival targets/routes immediately | Could represent persistence beyond a fixed style | Introduces unvalidated latent memory and likelihoods, larger state space, identifiability problems and more parameters before the simpler continuation mismatch is tested; no strength or capacity guarantee |

## Trade-off analysis

For a public history H and root action a, the new estimator targets E[U | H, a, e8 continuation, fixed rival model]. The old estimator uses tree/economic future control. Neither is the realized unknown opponent's exact value. The new experiment compares the two complete decision packages; it cannot attribute a change to a single factor because continuation, future control, sampling allocation and tie handling change together.

Terminal roots remove the leaf-tail approximation from this particular comparison. They do not validate opening play, the four rival styles, true long-term goals, Monte Carlo seed robustness or fresh full-match strength. Equal simulated-physics budgets are not equal wall time: report public reconstruction, policy calls, inference and simulation cost separately. A small empirical advantage has no reliable statistical certificate under this sample size.

## Consequences

- The one-step evaluator has an explicit, reproducible continuation target and no privileged opponent identity or future move tape.
- Original sources, earlier negative evidence, the complete primary allocation and reserved evaluation outcomes remain preserved.
- A favorable diagnostic would justify further investigation. A deployed teacher, a distilled single-file policy and a one-step hybrid each require a fixed definition and fresh complete-match confirmation.
- The 2,000,000-match campaign and its full per-game BMCTS requirement remain incomplete. This evaluator does not replace either requirement with simulated paths or replays.

## Action items

1. Implement the separate public-only evaluator and independently test memory isolation, prefix reconstruction, simultaneous choices and complete physics coverage.
2. Review and publish the exact comparative protocol before preparing recommendations or alternatives.
3. Preserve all sixteen cases, failures and outcomes; independently audit the complete real branch set and statistics.
4. Use results to choose the next architecture experiment, then return to the frozen fresh full-match comparison, primary migration and original campaign scope.
