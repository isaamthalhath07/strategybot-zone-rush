## Limits

Instance immutability is sound for the exact trusted source policies. Python process isolation is not a hostile-code sandbox: deliberately malicious code could attack shared class/module objects or the filesystem. The reviewed source policies read public fields and build their own state; they do not modify supplied namedtuple class descriptors. Code-family eligibility, finite candidate qualification and original-game admission remain separate root-authority responsibilities. A guarded arbitrary source does not become qualified because this generic runner can execute it.

These CPU synthetic checks establish orchestration and evidence rejection, not CUDA speed, CUDA integration qualification, long-run performance, bot strength or completion of the user's original training target. The actor author's separate short synthetic checks cover exact e8/Blocker/Feint source compatibility and supported memory projections. A later authorized canonical-control benchmark must measure the complete actor/IPC/physics/two-referee/journal/full-audit path; none was launched by this review.
