# Pure future primary continuation recipes

This component is necessary scheduling/source-family machinery for the original
two-million-game goal. It does not play, prepare, write, sign, reserve, admit,
qualify or promote anything. No stage/candidate files, keys or ledger are made.

`classify_source(body)` requires exact frozen `GenomeSpace(bot.py).export` bytes
or exact Blocker/Feint `TemplateSpace.inspect_export` bytes. It recognizes e8 and
50d, rejects AST-equivalent/comment/correctness edits, and declares supported
focal legacy oracle coverage80/0/0 without granting runtime approval.

`stage_recipe(catalog_bytes, stage_index, eight_sources)` returns a serializable
`payload`, its digest and `candidate_sources` **in memory**. Only TRAIN stages5
through79 are allowed: the unchanged original catalog maps100×stage through
100×stage+99,200 episodes/map,8 distinct source/genotypes and exact e8 control.
It uses the fixed migration slot contract and original rival family multisets.
Every candidate has2500 slots;64 cells have39/40 games and candidate-field totals
are624..628, so fitness must use equal64-cell weights rather than assume625.

Actual rival seeds are injective Python65-bit integers above2^64. Family,
epsilon/commitment and grouped `.16` planner/research mutation use separate
versioned domains. `seed_blob`/`rival_seed_blob` expose lossless9-byte BLOB keys;
never cast these seeds through float or signed int64. Fresh focal IDs identify
instances without changing the original public-seat RNG initialization.

`population_recipe(stage, previous_envelope, study_envelope=None,
verify_evidence=..., allow_crossover=False)` requires a separate reviewed caller
verifier returning exact typed `TrainingEvidence`/`StudyEvidence` containers.
Neither construction of a container nor `approved=True` is admission. The real
owner bridge must authenticate complete raw evidence before returning them;
this pure module has no such authority.

Slots0..2 retain exact e8/Blocker/Feint references. Slots3/4 rank only the
immediately previous fully accepted TRAIN stage's exact rational64-cell means,
then raw score and SHA, skipping all three fixed references and duplicates.
At stage5 only, the e8 child parent is chosen between e8/50d by the COMPLETE
four-arm study means, then raw mean score and SHA; Blocker/Feint start from their references. Later each child
uses its family's best current-stage parent. Optional same-family grouped
crossover precedes mutation. E8 child mutation uses frozen default `.08` sparse
mutation; Blocker/Feint use `.06`, at most3 genes. All64 maximum dedup attempts
and lineage are preserved; exhaustion fails without replacement or tuning.
