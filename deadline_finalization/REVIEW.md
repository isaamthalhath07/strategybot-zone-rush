## Preserved trust and execution boundary

campaign/manifest, current original source closure, adapter source closure,
qualified rival source map, execution configuration and Python environment.
The prospectively signed amendment must precede heldout reservations. It binds
the original controller function code/default/closure contracts as well as
source-file hashes. Cache receipts have a distinct format/role and exact integer
zero execution/game/BMCTS credit. Existing owner scope/purpose primitives are
reused unchanged; no private material enters an actor or worker.

Creation calls the exact original acceptance-validation function with its code,
defaults and closure unchanged. Copied globals replace only its output verifier
with a passive wrapper that invokes the original and captures the returned
summary/aggregate once. The proof tree must match before and after this check.
This repeats the original **durable evidence validation**, not actor callbacks
or physical simulation; actual original/replay callbacks and both referees were
performed by the prior admitted runner. This distinction matters for zero new

Every reuse authenticates the certificate and current accepted receipt and
hashes the actual bytes of every bound proof file. There is no size/mtime
shortcut, missing-cache fallback, implicit certification or partial recovery.

parsed aggregate and complete parsed summary are linked to those bytes.

The phase adapter clones the original controller function graph into one
separate globals dictionary. The only revalidation replacement is `_verify_output`.
Crucially, `_execute` remains the **original function object with its original

## Limits

The cache trusts the owner MAC, source-reviewed original validator and prior
actual execution evidence. It is not hostile-host attestation. A trusted owner
able to rewrite code/data and re-sign arbitrary claims is outside this trust
model. Before/after scans and per-read hashing do not remove all adversarial
hash-then-use races; immutable evidence and trusted owner-local operation remain
required. The phase's original lineage checks still run; calling cache.read
alone does not certify a campaign or select a policy. Optional analysis files
are not integrity-certified by this cache and must be separately bound if used
as report evidence.

Production amendment publication, full original certification, actual byte-scan
timing and later phase execution belong to root. These synthetic checks supply
no new matches, actor callbacks, physics transitions, primary credit, complete
per-game BMCTS credit or promotion.
